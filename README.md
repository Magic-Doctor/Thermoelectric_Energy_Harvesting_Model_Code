The warehouse includes ANSYS APDL modeling code (FEA_multiple_heat_sources.txt, FEA_single_heat_sour.txt) and maltab code for calculating the full field temperature (Multiple_full_field_temperature.m, Single_full_field_temperature.m)

FEA_multiple_heat_sources.txt : Multiple heat sources modeling and calculation for ANSYS APDL

FEA_single_heat_sour.txt: Single heat source modeling and calculation for ANSYS APDL

Multiple_full_field_temperature.m : Theoretical calculation of full-field temperature of multiple heat sources for MATLAB 

Single_full_field_temperature.m : Theoretical calculation of full-field temperature of single heat sources for MATLAB
